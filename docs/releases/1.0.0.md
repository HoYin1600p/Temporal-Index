# Temporal Index 1.0.0

Temporal Index 1.0.0 is the first public release of the Vault Hunters temporal-item container.

## Highlights

- Store temporal shards and all 16 supported temporal relic types in one book.
- Hold up to 65,000 of each supported item.
- Select occupied entries with sneak + scroll and activate them from the main hand.
- Open the 17-slot inventory with sneak + right-click.
- Automatically collect temporal drops before backpack pickup upgrades.
- Let Vault Hunters own shard loot rolls, instant identification, relic duration, restrictions, and effects.
- See the selected relic or shard sprite on the book cover in every common render context.
- Read compact `99+` slot labels while retaining exact quantities in slot and book tooltips.

## Requirements

- Minecraft 1.18.2
- Forge 40.3.11 or a compatible Forge 40.x build
- Java 17
- A compatible Vault Hunters `the_vault` build
- Temporal Index installed on both client and server

## Installation

Place `temporal_index-1.0.0.jar` in the `mods` directory for the client and server. This release does not include a crafting recipe; pack authors can add one, and testers can obtain the item through the creative inventory or `/give @s temporal_index:temporal_index`.

## Compatibility validation

The source compiled successfully against four distinct Vault Hunters JARs represented across five CMA instances:

- Vault Hunters 3.21.5.6573
- Vault Hunters 3.21.6.6884
- Vault Hunters 3.21.62
- Vault Hunters 1.18.2-20.0.3-remastered.6909

The release was functionally tested in CMA Remastered in survival mode inside a generated Vault. Testing covered container layout, every selection slot, relic activation, shard routing, pickup priority, large stored counts, localized tooltips, and first-person cover rendering.

The release JAR was also loaded by Forge's dedicated game-test server target without Wold's Vaults. It completed mod construction, common setup, common mixins, event registration, and data-pack registration without loading client-only Temporal Index classes.

After the server-side packet hardening, the same JAR passed a CMA Remastered client smoke test on Forge 40.3.11. Server NBT readback confirmed sneak-scroll selection changes reached the integrated server.

See [compatibility.md](../compatibility.md) for JAR hashes and the repeatable verification procedure.

## Known limitations

- No built-in survival recipe is provided in 1.0.0.
- The book uses original functional placeholder textures and models pending final commissioned artwork.
- Future Vault Hunters releases may require a compatibility update if their temporal internals change.

## Data and upgrade notes

Back up worlds before installing or updating mods. Do not remove Temporal Index while stored items remain inside Index books. Generated relics that cannot fit in an Index or the player's inventory are dropped at the player's feet rather than rerolled or deleted.
