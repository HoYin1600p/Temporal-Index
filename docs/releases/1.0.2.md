# Temporal Index 1.0.2 - Render Calibration and Polish

Temporal Index 1.0.2 adds the survival recipe, finalizes the current book and cover-icon positioning, improves Temporal Shard feedback, and resolves the Remastered 6909 startup failure.

## Highlights

- Added a shaped 3×3 survival recipe using four Pogs, four Vault Essences, and one Temporal Shard.
- Added JSON-driven translation and rotation for the book model and all 17 cover icons in first person, third person, dropped-item, and item-frame views.
- Packaged the finalized book and Temporal Shard transforms and uses the finalized Lunar transform as the shared default for every temporal relic.
- Restricted the selected relic or shard sprite to the front cover.
- Added The Vault's completed-identification sound when a Temporal Shard is activated from the Index, without replaying the full rolling sequence.
- Improved the container count and tooltip presentation while retaining exact quantities.

## Temporary calibration menu

The render calibration menu remains included so new artwork can be aligned later. It has no default key assignment in this release. To use it, assign **Open Render Calibration** in Minecraft's Controls menu.

The renderer reads its JSON configuration independently from the menu. Existing external files at `config/temporal_index/item_render_transforms.json` continue to override the packaged defaults.

## Compatibility and safety

- Removed the mandatory `TemporalShardItem.getState` mixin injection that prevented Vault Remastered build 6909 from starting.
- Kept Wold's Vaults optional; Temporal Index requires only Vault Hunters at runtime.
- Verified compilation against the four distinct Vault Hunters JARs represented by the CMA instances: Remastered 6909, Wolds 6573, Third 6884, and Asgard 3.21.62.
- Temporal Index remains required on both the client and server.

## Requirements

- Minecraft 1.18.2
- Forge 40.3.11 or a compatible Forge 40.x build
- Java 17
- A compatible Vault Hunters `the_vault` build

## Installation

Place `temporal_index-1.0.2.jar` in the `mods` directory on both the client and server. Remove older Temporal Index JARs and back up worlds before updating.
